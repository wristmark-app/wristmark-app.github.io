Accessibility

Beiwen, also known as AlwaysOn AI, is designed to work with Apple's built-in accessibility technologies so more people can use the app comfortably on iPhone.

Supported features

  • Works with VoiceOver and standard accessibility labels on major navigation and action controls.
  • Uses system text, buttons, sheets, and lists where possible so it follows native iOS accessibility behavior.
  • Supports Dynamic Type and larger text sizes through iOS text scaling.
  • Supports Dark Interface on iPhone.

AI content notes

Beiwen is an offline-first emergency AI assistant. Answers, translations, and image-assisted judgment may vary depending on the prompt and the on-device model. Please review output manually when using assistive technologies in a high-stakes situation.
